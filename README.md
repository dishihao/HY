# 薄荷含量测定计算

纸质检验记录式布局的静态网页计算工具，适合直接部署到 GitHub Pages。

## 功能

- 对照品连续 5 针平均峰面积与 RSD（样本标准偏差，n-1）
- 两份供试品含量、相对偏差、平均含量自动计算
- 数值修约采用“四舍六入五成双”
- 含量 X 比标准规定多保留 1 位小数
- 相对偏差比标准规定少保留 1 位小数，且按页面已修约的 X1/X2 计算并取绝对值
- 平均含量与标准规定保留相同小数位
- RSD 固定保留 1 位小数
- 自定义标准规定和“不得少于/不得高于”判定
- 浏览器本地自动保存、打印/保存 PDF、复制抄写摘要
- 无后端、无外部依赖，可离线使用

## 默认仪器

- 电子天平：AVW120D，编号 HY-TP-09
- 气相色谱仪：8860，编号 HY-QX-01

## 计算公式

```text
X = (A样平均 × C对 × f样 × V对)
    / (A对平均 × W样 × 1000 × (1-Q%) × V样) × 100%
```

相对偏差：

```text
|X1(已修约) - X2(已修约)| / [X1(已修约) + X2(已修约)] × 100%
```
