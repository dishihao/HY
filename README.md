# 检验项目计算工具

按纸质检验记录布局设计的静态网页工具，每个检验项目使用独立页面，直接部署在 GitHub Pages。

## 页面

- `index.html`：项目选择首页
- `assay.html`：气相含量测定
- `moisture.html`：水分测定（烘干法）
- `ash.html`：总灰分测定
- `sulfur-dioxide.html`：二氧化硫残留量测定

## 共同功能

- 每个项目的数据和计算互相独立
- 可输入格使用浅黄色醒目标注
- 自动计算结果使用白底双下划线
- 两份平行样结果、相对偏差、平均值和标准判定
- 数值修约采用“四舍六入五成双”
- 可载入示例、复制结果、打印或保存 PDF
- 页面刷新后清空当前数据
- 打印时自动恢复黑白纸质记录效果

## 注意

水分、总灰分的具体取样量、温度、时间和恒重条件应按实际检验标准或 SOP 执行。二氧化硫页面的换算系数 `F` 必须按实际滴定液、标定结果及检验 SOP 填写，网页不预设固定化学当量。
